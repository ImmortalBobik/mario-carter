# 🏎️ Mario Carter: CarterPCs Edition

A fast-paced 3D arcade kart racer starring tech YouTuber **CarterPCs**! Race as Carter across high-octane tracks powered by Three.js, complete with procedural audio, custom CPU opponents, item boxes (RTX 5090 GPU boosts, Thermal Paste banana peels, RAM sticks, and Watercooling Shields), drift mechanics, and Carter voice lines.

## 🎮 Play Online
- **Live Demo (GitHub Pages):** [https://ImmortalBobik.github.io/mario-carter/](https://ImmortalBobik.github.io/mario-carter/)

## 🚀 Controls
- **Accelerate / Steer:** `W` / `A` / `S` / `D` or `Arrow Keys`
- **Drift:** `Shift` or `Space` (Hold while turning for sparks & speed boost!)
- **Use Item:** `E` or `Ctrl` or `Enter`
- **Reset Kart:** `R`
- **Toggle Audio:** `M` or Speaker icon

## 🛠️ Features
- **3D Graphics:** Built with Three.js (custom karts, animated Carter head, particle exhausts, drift sparks).
- **Tech Themed Power-ups:**
  - ⚡ **RTX 5090 GPU:** Massive overclock nitrous boost!
  - 🍌 **Thermal Paste:** Slip hazards dropped behind you.
  - 🛡️ **Watercooling AIO:** Temporary invincibility shield.
  - 💾 **RAM Stick:** High-speed homing projectile targeting leading racers.
  - 💣 **Cable Mess:** Explosive trap.
- **Sound & Music:** Procedural Web Audio synthesizer for kart engine pitch, drift squeals, item sound effects, and synthwave racing soundtrack.
- **Dynamic Leaderboards & Lap Timing:** 3-lap grand prix racing against smart AI opponents.

## 📦 Local Setup
Simply clone and open `index.html` in any modern web browser or serve with:
```bash
npx serve .
# or
python -m http.server 8000
```
